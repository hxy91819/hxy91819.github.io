Privacy Policy

agent-gdrive is used only by its owner. This policy describes how it handles Google user data.

Data accessed

With the user's consent, it uses read-only Google Drive access to download or export files the user explicitly requests.

Use and storage

Files are downloaded to the owner's own server only for the owner to read, and temporary copies are deleted after use. The OAuth token is stored only in a local configuration file on that server.

Sharing

Google user data is not sold, shared with, or transferred to any third party, and is not used for advertising or to train AI models.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
